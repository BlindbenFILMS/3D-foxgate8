MERU VOICE PACK - all 1,976 voice lines for Meru

vo/<id>.mp3       one clip per script row, named by the row id in MERU_ALL.txt
                  (for example vo/lanes-gale-q1.mp3)
meru_voice.json   one entry per clip: id, file, fox, voice, delivery, text,
                  scene and length in seconds, in script order

How to use in the game:
- To play a row, load "vo/" + id + ".mp3". The game's existing row ids match the file names.
- Clips are already trimmed and levelled. Shouts are a little louder and whispers a little
  quieter on purpose, so play them all at the same volume.
- Two-fox conversations: play every clip with the same "scene" in the
  order listed, leaving about 0.4 seconds between clips.
- FOX (the player) is Ben's own voice. The narrator is not in this pack.
- Captions: use the "text" field. It is exactly what is spoken.

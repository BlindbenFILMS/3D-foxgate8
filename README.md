# FOX GATE 8 · 3D

The new 3D home of 8 GATES: **8 GATES Stewards**. Up to 5 friends and family each become the steward of a newly discovered world, grow it, defend it while they're away, and move through weekly story chapters together. Solo play works too.

- Play: https://blindbenfilms.github.io/FOXgate8-3D/
- Game plan (doc): https://claude.ai/code/artifact/3eaad9ff-d517-4128-9595-08514c3a8552
- The old site (2D worlds, the Blind Canvas gallery, AR) stays at https://blindbenfilms.github.io/FOXgate8/

## Folders
- Root: the Meru 3D pack (open `Meru Town Square.dc.html`; read `START_HERE.md`, `PROJECT_NOTES.md`, `BUILD_PLAN.md`)
- `minigames/`: 35 shop and job minigames (each folder opens straight into its game; `minigames/index.html` lists them all) plus `minigames/meru/` and the minigame music in `minigames/MUSIC/`
- `STEWARDS_PLAN.md`: the 8 GATES Stewards phases
- `MERU/ GAYA/ jidda/ KUFA/ KYOTO/ LUXOR/ nebo/ SPACE/ UR/ zion/`: music and video carried over from FOXgate8, same names and paths
- New game code goes in its own folders (see CLAUDE.md)

## Deploy
Claude writes files into this folder; Ben commits and pushes with GitHub Desktop; GitHub Pages (Settings → Pages → main, / root) publishes it.
